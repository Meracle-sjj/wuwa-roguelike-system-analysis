## 各局支撑什么

- **R03狂欢：** 齿轮之心改变回能/延时的需求；免死预期与后续风险判断分开记录。
- **R04雷暴：** 跟随稀有度提示并保持正常操作，获得配套核心，普通与追加两阶段通过；有两处更偏好另一项但仍按约定选取。
- **R05飓风：** 声骸轮换到解梦集中释放，凋零的梦改变可用时段；维里奈参与声骸触发。
- **R06坚盾：** 回能充足时拒绝齿轮、后期改用千咲；领域生成的重击类伤害与直接重击动作区分。

后续明确确认：R05/R06最后击败的均为追加挑战；R04分支均选困难；绯雪、千咲均为零共鸣链且带专属武器。商店两条规则与普通通关满周进度另见[来源与方法](../来源与方法.md)。

## 文件怎么读

原始ASR可能误识别专名和混入游戏台词；修正稿用方括号及复核注区分名称校正、未决词和整理者解释。修正稿里的某些待确认项是当时状态，后续确认在各稿顶部单列，原话不重写成事后已知。录音时长仅供段落定位，不是可下载的媒体文件。

公开整理替换本地路径与附件链接、补入后续确认，并撤下录音文件及下载入口。原始ASR按原文件复制，不重新转写；近似时间不作精确计时。本人感受与规则来源分开，未播报不填成未发生。
